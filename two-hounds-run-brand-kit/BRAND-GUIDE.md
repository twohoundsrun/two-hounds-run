# Two Hounds Run Brand Guide

**Brand line:** Practical tools. Built for the long run.

Two Hounds Run is a flexible product-studio identity for sports, business,
logistics, websites, and practical software. The two real hounds make it
personal; the paired sweep lines suggest motion, delivery routes, progress,
and software running.

## Logo files and intended use

1. **01-primary-logo-transparent.png — Primary logo**
   - Default logo for websites, proposals, invoices, project pages, and print.
   - Use on white, pale gray, or other quiet backgrounds.
   - Recommended minimum width: 280 px.

2. **02-mark-only-transparent.png — Standalone logo mark**
   - Use where the full name is already visible or space is limited.
   - Best for app tiles, project badges, stickers, and compact navigation.

3. **03-social-avatar.png — Social avatar / app icon**
   - Ready for Facebook, Instagram, X, TikTok, Threads, YouTube, GitHub,
     LinkedIn, and other square or circular profile crops.
   - Keep the supplied padding so neither dog is cut off by circular crops.

4. **04-profile-banner.png — Profile banner**
   - Designed for GitHub and adaptable to X, Facebook, LinkedIn, and YouTube.
   - Check each platform's crop preview before publishing.

5. **05-website-header.png — Website hero/header**
   - Homepage hero artwork with the brand message already composed.
   - Use as a full-width image or as the visual reference for a coded hero.

6. **06-watermark-white-transparent.png — White watermark**
   - Use over dark photos, videos, screenshots, sports graphics, and reels.
   - Reduce opacity further when the underlying content needs more emphasis.

7. **07-watermark-navy-transparent.png — Dark watermark**
   - Use over light photos, documents, proposals, and screenshots.

8. **08-stacked-logo-transparent.png — Stacked logo**
   - Use for square layouts, centered document covers, merchandise, and signs.

9. **09-brand-style-guide.svg — Color and typography reference**
   - Quick visual reference for future websites, graphics, and documents.

10. **favicons/**
    - `favicon-32.png`: browser tabs and legacy favicon use.
    - `favicon-192.png`: Android and progressive web apps.
    - `favicon-512.png`: high-resolution app and PWA icon.
    - `apple-touch-icon.png`: Apple home-screen bookmark.

## Typography

- **Headlines and display text:** Sora Bold (700)
- **Subheads and buttons:** Sora SemiBold (600)
- **Body copy and interface text:** Inter Regular/Medium (400/500)
- **Wordmark:** use the supplied logo artwork; do not recreate it by typing.

Sora and Inter are free through Google Fonts and work on websites, Windows,
macOS, ChromeOS, Android, and iOS.

## Basic rules

- Leave clear space around the logo equal to roughly one hound ear.
- Do not stretch, rotate, recolor, outline, or add drop shadows to the logo.
- Keep the tan as a character accent rather than a major interface color.
- Use the full logo when introducing the brand and the mark when the name is
  already nearby.
- For trademark use, add `TM` only after deciding how and where the brand will
  be used. Do not add the registered symbol unless a registration is granted.
